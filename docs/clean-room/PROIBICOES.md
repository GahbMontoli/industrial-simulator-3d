# Proibições clean-room

Não inserir neste repositório:

- código decompilado ou reconstruído de produtos de terceiros;
- DLLs ou executáveis do Factory I/O;
- cenas `.factoryio` ou conversores desse formato;
- modelos, texturas, sons, ícones, textos ou capturas reutilizadas como assets;
- nomes, logotipos ou aparência que indiquem afiliação;
- mecanismos de ativação, chaves, tokens ou material de licenciamento;
- instruções destinadas a contornar controles de acesso.

Somente requisitos funcionais abstratos, padrões públicos, testes black-box autorizados e recursos criados para este produto podem orientar a implementação.
